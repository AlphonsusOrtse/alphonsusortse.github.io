## Run locally

This is a static website; no Python environment or package installation is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/AlphonsusOrtse/alphonsusortse.github.io.git
   cd alphonsusortse.github.io
   ```
2. Open `index.html` in a browser, or start a local server:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit http://localhost:8000.

## Deployment

The site is designed to be hosted using GitHub Pages. In repository **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)**.
